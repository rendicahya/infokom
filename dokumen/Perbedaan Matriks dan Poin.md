# Perbedaan Matriks Penilaian dan Tabel Poin

Dokumen ini mencatat perbedaan antara bagian matriks (`Matriks Penilaian ... Unggul.md`) dan tabel bobot di akhir dokumen LAM INFOKOM (`Poin ....md`). Keduanya berasal dari dokumen yang sama, yaitu Matriks Penilaian Kinerja Program Studi dan Suplemen LAM INFOKOM 2.1 - 2025.

**Acuan yang digunakan adalah Rekap Hasil Hitung di masing-masing file Matriks**, bukan tabel di file Poin.

Nomor butir Matriks = nomor Poin + 2, karena butir 1–2 Matriks adalah Kondisi Eksternal dan Profil UPPS.
